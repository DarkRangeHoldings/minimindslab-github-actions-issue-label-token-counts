# Text Token Counts

Count lowercase ASCII alphanumeric tokens in issue or PR text and return deterministic frequencies for lightweight CI checks.

Generated by MiniMindsLab 02.13 GitHub Action Factory.

## Usage

```yaml
- uses: ./path-to-action
  id: miniminds
  with:
    payload: '{"text":"Red blue red, BLUE 42."}'
- run: echo '${{ steps.miniminds.outputs.result }}'
```

Runtime: Node 24. No external dependencies. No network access.
